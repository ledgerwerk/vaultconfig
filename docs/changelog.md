# Changelog

## [v0.3.0] - 2026-11-19

### Added

- Added `FileVault` and optional `KeyringVault` for storing named secrets outside
  configuration files

### Changed

- **BREAKING:** Changed CLI format detection to require `--format` in directories with
  mixed configuration formats

### Fixed

- Fixed handling of schema-marked sensitive fields inside nested configuration values
- Fixed partial bulk encryption updates by attempting to restore files after a write
  failure

### Removed

- **BREAKING:** Removed support for Python runtimes older than 3.10
- **BREAKING:** Removed `vaultconfig init --encrypt`; use `encrypt-dir` or
  `encrypt-file` instead

### Security

- Secured V1 parsing against trailing data and limited password-provider commands to 30
  seconds

### Documentation

- Documented how configuration, encrypted files, and the two secret backends fit
  together
